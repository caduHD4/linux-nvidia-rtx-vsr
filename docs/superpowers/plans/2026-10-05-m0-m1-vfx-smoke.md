# M0–M1 NVIDIA VFX Smoke Test Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preserve and validate the Python VSR baseline, then deliver a minimal C++ `vsr-smoke` that runs NVIDIA VideoSuperRes on persistent GPU images.

**Architecture:** A small diagnostic layer discovers the installed Python and C++ SDK assets without hard-coded interpreter versions. CMake exposes the official VFX SDK through one imported target; a focused RAII C++ session owns the VFX effect, stream, and images while the CLI handles only validation and reporting.

**Tech Stack:** C++20, CMake 3.25+, CTest, Python 3.10+ standard library, NVIDIA VFX SDK 1.3.0.0, CUDA driver/runtime supplied by NVIDIA dependencies.

**Spec:** `docs/specs/2026-10-05-m0-m1-vfx-smoke-design.md`

## Global Constraints

- Use the official NVIDIA VFX SDK and GPU buffers; do not invent ABI declarations.
- Do not vendor NVIDIA proprietary libraries or models.
- Python is diagnostic-only and never enters a playback hot path.
- Do not add WebGPU, capture, HTTP proxy, re-encoding, or per-frame CPU copies.
- `NvVFX_Load()` runs once, never once per frame.
- Every success claim requires the build/test/log that proves it.
- SDK absence must produce an actionable diagnostic, not a CPU fallback.
- M0–M1 support only RGBA8/BGRA8 synthetic frames and quality modes 1–4.

## Review Focus

- `nvidia-smi` banners containing only `KMD Version:` must parse driver 610.57.04 correctly; Task 1 tests it.
- Virtual environments using Python versions other than 3.11 must resolve their real site-packages directory; Task 1 tests it.
- Missing VFX SDK headers or libraries must fail configuration with an actionable message and no ABI shim; Task 2 tests it.
- Invalid dimensions, non-upscaling output, and reserved quality values must fail before GPU initialization; Task 3 tests them.
- A VFX failure after partial initialization must release every acquired resource and never print `PASS`; Task 4 tests it with a fake API.
