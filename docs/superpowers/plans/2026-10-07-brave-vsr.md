# Brave VSR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver a tested Brave browser with the existing NVIDIA VSR integration.
**Architecture:** Official pinned Brave plus a reproducible VSR delta, separate output/profile, external NVIDIA SDK.
**Tech Stack:** Brave/Chromium C++, GN/Ninja, Node/pnpm, Python, CUDA/VFX.
**Spec:** docs/specs/2026-10-07-brave-vsr-design.md

## Global constraints
- Brave v1.96.61, Chromium154.0.8037.98; preserve existing working Chromium.
- Fullscreen-only, target2160, mode4 strength1.0, native denoise11, sharpen0.35; no protected/HDR processing or CPU pixel transfers.
- No SDK/build outputs/credentials in Git; disclose GPU sandbox limitation.

## Review focus
- Overlapping Brave patches retain Brave behavior.
- Existing official Brave and Chromium profiles remain separate.
- Prerequisite checks alone never count as inference evidence.
- Future upstream conflicts stop automation rather than publishing partial patches.
- SDK licensing and hosted runner capacity limit automatic builds.

- [x] Export and apply integration delta after Brave patches. Files: brave/patches/nvidia-vsr.patch and tools/brave/apply.py. Verify clean apply, staged backend and GN generation; reject wrong pins/conflicts. Test rejection and repeat-application behavior.
